どこへ ret する？

ready queue と保存された rsp を追って、初回開始と再開の違いを確かめる演習です。ブラウザだけで動きます。

到達目標

各切替えで次に実行する論理スレッドと st_ctx_swap の ret の行き先を予測し、その根拠を「queue の操作」と「ctx.rsp が指す値」で説明できる。

これは st.c と ctx.S の動作を記号化したモデルです。実際のレジスタ値やアドレスを表示する実行器ではありません。実機の確認には README の gdb 演習を使ってください。

始める前に（約3分）

目安は全体で15〜20分。README の前提知識と「コンテキストスイッチ」の1〜3を先に読んでください。

ctx.rsp はスタック上の場所のアドレスです。その場所に入った値が戻り先です。以下の memory[ctx.rsp] はその場所の8バイトを表します。

保存: prev.ctx.rsp = rsp
復元: rsp = next.ctx.rsp
ret : rip = memory[rsp]; rsp = rsp + 8

この図は rsp と ret のみを抜粋しています。実装は他のレジスタとFP制御状態も保存・復元します。呼出し連鎖は README の標準ビルド（最適化なし）を前提にします。
